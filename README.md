# lvaraerp_1# LvaraERP | PT Riliv Psikologi Indonesia

Prototype frontend ERP untuk mendukung simulasi operasional layanan health-tech dan konseling.

## Fitur
- Dashboard ringkasan sesi, klien, pendapatan, dan status jadwal
- CRUD dasar data klien
- CRUD dasar jadwal konseling
- Tambah psikolog, layanan, dan sumber daya
- Ringkasan transaksi dan ekspor CSV
- Laporan operasional contoh
- Dark mode dan layout responsif
- Penyimpanan browser dengan `localStorage`

## Menjalankan secara lokal
1. Ekstrak folder `LvaraERP`.
2. Buka folder tersebut di VS Code.
3. Buka `index.html` menggunakan ekstensi **Live Server**, atau buka langsung di browser.
4. Data demo disimpan di browser/perangkat yang sama.

## Catatan penting
Ini hanya prototype UI dan menggunakan data contoh. Belum ada backend, autentikasi, database bersama, kontrol akses berbasis peran, atau integrasi pembayaran/video call. Jangan gunakan untuk menyimpan rekam medis, catatan terapi, atau data kesehatan pribadi sungguhan. Untuk penggunaan produksi, dibutuhkan backend aman, enkripsi, audit log, pengelolaan consent, pembatasan akses, dan peninjauan kepatuhan privasi serta regulasi yang berlaku.

Angka dashboard dan nama klien/psikolog adalah data ilustratif, bukan klaim tentang data aktual PT Riliv Psikologi Indonesia.
